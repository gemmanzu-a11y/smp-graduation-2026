**2023~2025년 전체 완비 자료가 아닙니다. 2024년은 API 200일분을 확보했으며 166일이 남아 있습니다. 모델 READY가 아닙니다.**

## 연간 파일

출처: [한국전력거래소_연료원별 시간대별 설비용량 및 전력거래량](https://www.data.go.kr/data/15127395/fileData.do).

단위는 원본 `전력거래량(MWh)` 열의 **MWh**입니다. 전력시장 참여 발전기의 송전단 전력거래량이며 설비용량(MW)·입찰량·전국 전체 발전량과 구분합니다. 육지/제주 구분 열이 없어 육지 단독이라고 표시하지 않았습니다. LNG에 대해 제주분이 제외됐다고 가정하지 마세요.

열:
- timestamp: KST +09:00, 원본 01~24를 00~23 시작 슬롯으로 변환.
- lng_generation_mwh: LNG.
- bituminous_coal_generation_mwh: 유연탄.
- anthracite_coal_generation_mwh: 무연탄.
- nuclear_generation_mwh: 원자력.
- coal_generation_mwh: 유연탄+무연탄. 다른 연료를 포함하지 않음.

2023/2025년 위 변수들의 값 결측은 없습니다. 2023년은 원본이 정수 MWh로 제공되며, 일부 API 값 차이는 반올림 범위를 초과합니다. 수정정산 등 원인은 미확정입니다. 2023년 대조 9,216쌍에서 절대차 1 초과 369쌍, 최대차 약 829.259입니다. 2025년 대조 96쌍은 최대차 약 0.0005입니다. API와 연간 파일을 동일 버전이라고 간주하지 않습니다.

## API 부분 파일

출처: [한국전력거래소_발전원별 발전량 API](https://www.data.go.kr/data/15106744/openapi.do).

`tradeYmd`, `tradeNo`, `fuelTpCd`, `amgo` 등 원본 필드를 보존하고 timestamp를 추가했습니다. **API amgo의 단위는 응답·명세만으로 독립 확인하지 못해 임의로 MW/MWh로 열 이름을 바꾸지 않았습니다.** 연간 MWh와 대조 결과는 manifest에 기록했습니다. 발전원 `유전` 등의 원본 코드도 변경하지 않았습니다.

2024년 API 조회를 이어 진행했고, 현재 200일·38,400행을 확보했습니다. 2023/2025년 API 수집분과 합치면 총 297일·57,024행입니다. 이후 일일 호출 한도(HTTP 429)에 도달해 중단했습니다. 2024년 2월 29일은 정상 응답 0건으로, 권한/한도 오류와 구분합니다. 키 값은 저장하지 않았습니다.

## 2024년이 없는 이유와 해결

공식 연간 목록의 2024년 상세항목은 실제 첨부파일명이 `신재생 연료원별 설비용량 및 전력거래량_2024.csv`이며 LNG·유연탄·무연탄·원자력이 없습니다. 파일의 신재생 행을 0 발전량이나 다른 연료로 바꾸지 않았습니다.

해결 방법:
1. API 한도가 다시 사용 가능해지면 `pending_dates_2024.csv`의 166일만 이어 수집.
2. 운영계정·트래픽 증설로 일일 허용량을 늘려 수집.
3. 제공기관에 2024년 전체 연료원 파일 정정/제공 요청.

한도 초기화의 정확한 시각은 이 서비스에 대해 아직 확인하지 못했습니다. 자정 정각에 반드시 해제된다고 보장하지 않습니다.

키는 본인의 환경변수에 설정합니다. API 키는 이 폴더에 없습니다.

```sh
# 저장소 루트. 새 API 호출 없이 미확보 날짜만 확인
1120gradpj/.venv/bin/python 1120gradpj/scripts/collect_generation_history.py --plan-only
# 한도 사용 가능 후 2024년만 이어받기. 저장된 날짜는 재사용
1120gradpj/.venv/bin/python 1120gradpj/scripts/collect_generation_history.py --start 2024-01-01 --end 2024-12-31
```

공식 파일 ID·원본 해시·조회 영수증·공유 CSV 해시는 manifest.json에 있습니다. 본 공유는 공공 원자료 정리이며 모델 학습이나 실제 72시간 예측을 실행한 결과가 아닙니다.

## 2026-11-18 추가 수집

새로 제공된 서비스 키로 98일분을 추가 수집했습니다. 현재 2024-01-01~2024-04-09 중 2월 29일을 제외한 99일과 기존 7월 1일 1일, 합계 100일입니다. 빈 날짜를 0이나 보간값으로 채우지 않았습니다. 2월 29일은 API 원문의 정상 0건 응답을 별도 보존했습니다. 키 값·계정정보는 공개하지 않았습니다.
