# 전력예보 발표

워크스페이스 루트에서:

```sh
cd presentation
python3 -m http.server 5180
```

본편: http://localhost:5180 / 발표자: http://localhost:5180/presenter.html
빌드·패키지 설치·외부 연결 없이 실행됩니다. 서버는 Ctrl+C로 종료합니다.

- 다음 단계: →, ↓, Space, Enter / 이전: ←, ↑, Backspace
- F 전체화면, A 현재 장 모두 펼치기, P 발표자 창
- Home 본편 처음, End 본편 마지막 장의 마지막 단계
- `#10.3` 형태로 장·단계 직접 진입. 단계는 1부터 시작합니다.
- 입력·버튼·선택 상자에 포커스가 있으면 발표 단축키를 가로채지 않습니다. 빈 무대를 클릭하면 다시 키를 사용할 수 있습니다.
- 마지막 장 버튼으로 기술 부록을 열고 Escape 또는 돌아가기 버튼으로 닫습니다.
- 발표자 창을 늦게 열어도 본편에 현재 상태를 요청합니다. 같은 호스트·포트에서 열어야 합니다. 타이머는 본편을 연 시점 기준이며 발표자 창에서 초기화할 수 있습니다.

## 데이터와 근거

- `data/v5_2023-10-01.csv`: `../v20/outputs/next_day_smp_forecast_tuned.csv`의 원본 복사. V5 선택 모델의 과거 검증일 24개 예측과 급등 확률입니다. CSV datetime 기준 00~23시로 정렬하며 adapter의 hour=24 표기를 시각으로 해석하지 않습니다.
- `data.js`: 이 CSV를 변환한 오프라인 런타임 데이터. 합성 가격을 사용하지 않았습니다.
- V5 MAE 11.093786, R² 0.642919, Daily MAE 13.575802, regret 2.464330: `../v20/outputs/v5_metrics.json`, `../v20/docs/V5_REPRODUCTION.md`, `../v20/docs/reproduction.json`.
- 혼합 69/31, 임계 0.45, 특성 63: V5 재현 기록. policy JSON·학습 데이터·평가 CSV는 Git 제외 상태로 현재 checkout에 없으며 다시 학습하지 않았습니다.
- HGB 12.03, 검증 MAE 8.66/7.64/7.39, Daily/HGB R² 0.269/0.604, Daily regret 18.92: 사용자가 제공한 V5 발표 원고. 같은 V5 실험의 원고 수치이며 현재 저장소에서 해당 비교 CSV를 직접 대조하지 못했습니다. 부록에도 이를 명시했습니다.
- regret: `../v20/model/v5.py`의 `charging_backtest_rows`, `cheapest_window`. 날짜별 실제 SMP 합의 차이를 계산하고 2·3·4·5·6·8시간별 평균을 다시 평균합니다. kWh를 곱한 고객 요금이 아닙니다. 87%는 (18.92−2.46)/18.92≈87.0%, MAE 감소는 약 18.3%입니다.
- 11장: 2023-10-01 실제값 원본·PDF가 없어 제공 원고의 한계를 정량 눈금 없는 도식으로 표현했습니다. 실제 측정 곡선이 아닙니다. 시간대별 MAE 원본도 없어 부록에 수치 그래프를 넣지 않았습니다.
- 1·10장의 시간축은 위치 설명용 도식입니다. 15장의 선택 조건은 날씨 규칙 설명용 입력입니다. 내장 데모는 2023-10-01 실제 저장 예측을 사용합니다. 시연일은 Asia/Seoul 현재 날짜를 따로 표시합니다.
- 데이터 흐름: `../v20/services/v5_web_adapter.py`, 가격 날씨: `../v20/model/v5.py`의 `price_weather_label`.

## 기존 자료와 구분·수정

기존 웹·분석 파일을 변경하지 않았습니다. 로컬 deck/ 엔진과 발표 PDF를 찾지 못했고 Claude 레퍼런스 URL은 접근 실패해 새 바닐라 엔진을 작성했습니다. 표지는 요청한 등록명 ‘전력예보’를 사용했습니다. 저장소에서 별도의 공식 등록 제목은 확인하지 못했습니다.

충전 계산은 `60×(80−35)/100=27kWh`, `ceil(27/7)=4시간`으로 정정했습니다. 본 데모는 효율 100%, 일정 출력, 동일 1시간 슬롯, 당일 연결 범위 안 연속 구간입니다. 밤샘 연결은 지원하지 않으며 종료가 시작보다 늦어야 한다는 이유를 표시합니다.

현재 `../v20/docs/index.html`은 후속 V20 정적 웹이며 분산 충전·다른 모델과 평가집단을 사용합니다. V5 실험과 섞지 않았습니다. `WEB_V20_PUBLIC_README.md`는 GitHub Pages 발행을 미확인으로 기재합니다. 따라서 확인되지 않은 공개 주소 버튼은 넣지 않았고 로컬 데모만으로 발표가 끝납니다. V5의 기존 Streamlit Cloud 설명은 부록 연결 구조에 남겼으며 실시간 배포 시연을 주장하지 않습니다.

자동 실행·푸시·방전은 시연하지 않습니다. LSTM의 미래 실측 입력 문제는 제공 원고에 따른 설명이며 구형 원본은 현재 checkout에서 확인하지 못했습니다.

## 이번 실행의 검수 기록

- `node qa/check.mjs` 통과: 17장·50단계·635초, 대본 마커 수 일치, 모든 reveal 단계 범위, 24시간 완전성, 가능한 모든 길이/연결 범위에서 최소 구간 전수 대조, 가격 날씨 경계값.
- 기본값: 4시간, 02:00~06:00, 평균 SMP 82.65187원/kWh. 목표 90%: 5시간, 02:00~07:00, 84.12952원/kWh. 가용시간 부족 시 추천 함수 null 확인.
- JS 구문 검사와 Python 문법 검사 통과. 본편·발표자 HTML 및 모든 런타임 자산 로컬 HTTP 200 확인.
- 서버는 샌드박스 소켓 바인딩 제한 때문에 승인된 로컬 실행으로 HTTP 검증했습니다.
- **미검증**: 전 장 마지막/중간 단계 스크린샷, 1600×900·1366×768 시각적 QA, 브라우저 콘솔, 실제 키 이동·A 이후 이동, 늦게 연 발표자 창의 실제 동기화, 실제 폼 입력·초기화 조작. Chrome 탐색 API에서 `timeoutMs` 오류가 발생했고 네이티브 우회 중 사용자 브라우저 전환이 반복되어 UI 검수를 중단했습니다. 따라서 이 항목들의 통과나 캡처 완료를 주장하지 않습니다.
- `qa/`에는 자동 계산·구조 검사만 있으며 화면 캡처는 없습니다. 리허설 전 위 미검증 항목을 브라우저에서 확인해야 합니다.
