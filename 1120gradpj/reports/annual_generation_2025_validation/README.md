## 원자료 정의

[KPX 공식 파일 설명](https://www.data.go.kr/data/15127395/fileData.do)에 따르면 전력시장에서 거래하는 발전기의 송전단 전력거래량(발전량)이며 소내용 및 주변압기 손실을 제외합니다. 설비용량 MW가 아니라 `전력거래량(MWh)`를 사용합니다. 전국 모든 발전소의 총발전량, 공급가능용량, 입찰량과 구분합니다. 지역 필드가 없어 육지 단독 자료로 명명할 수 없습니다. 공식 API 설명 역시 전력거래 정산자료라고 명시하며 수정정산에 따라 변동할 수 있습니다.

## 보완 효과 및 적용 방법

- 2025년 변수별 확보24시간 →8,760시간, 미확보8,736시간 →0시간입니다. LNG·원자력·석탄 모두 해당합니다.
- 2025년은 연간 CSV를 단일 출처로 채택하는 것이 적절합니다. API와 날짜별로 뒤섞거나 두 파일의 행을 중복 합산하지 않습니다.
- 새 공통 데이터 버전에서 원본 출처·해시·시장 범위·단위를 기록하고 실측72시간 지연을 그대로 적용합니다.
- 달력상2024년 말 또는2026년 초에 걸친 데이터는 별도 연도 원본이 필요합니다. 이 검증으로2024년 누락이 해결되는 것은 아닙니다.
- 모델 재학습 전 이력창과 모든 평가 발행일의 입력을 다시 생성해야 합니다. 기존 LSTM/SARIMAX 성능표는 보완 전 실험으로 보존합니다.

## 남은 한계

1. 96쌍의 일치는 강한 호환 근거지만 나머지364일의 API 일치를 증명하지 않습니다.
2. [공식 파일](https://www.data.go.kr/data/15127395/fileData.do)과 [API](https://www.data.go.kr/data/15106744/openapi.do)는 수정정산으로 값이 바뀔 수 있습니다. 완전히 같은 발표본이라고 주장하지 않습니다.
3. 현재 연간 파일을 확보했다는 사실은2025년 각 예측일에 해당 값이72시간 안에 공개됐다는 증거가 아닙니다. 과거 발표본을 복원한 자료가 아니므로 기존 지연 가정을 계속 명시해야 합니다.
4. 용량 대비 에너지 범위 점검은 내부 타당성 확인이며 자료 범위 동등성을 보증하지 않습니다. 연료별 용량 초과 건수 등은 validation.json에 기록했습니다.
5. 성능 개선은 아직 평가하지 않았습니다. 2025년 하반기를 본 뒤 구성한 후속 실험이므로 재평가 시 최초의 독립 Final Test와 구분합니다.
