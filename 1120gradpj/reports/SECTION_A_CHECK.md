## 실제 수요 기존 파일의 2023~2025 커버리지

| 연도 | 필요 시간 | 유효 시간 | 결측 시간 |
|---|---:|---:|---:|
| 2023 | 8,760 | 8,648 | 112 |
| 2024 | 8,784 | 8,445 | 339 |
| 2025 | 8,760 | 8,116 | 644 |

전체 26,304시간 중 유효 25,209, 결측 1,095시간(4.16%). 시간 행 자체 누락 192시간, 기존 행의 5분 표본 부족·값 결측 903시간.

현재 방식은 5분 현재부하 MW 12개의 평균을 시간별 수요 MW로 만든다. 12개가 모이지 않은 시간은 NaN으로 유지하며 0이나 일 최대수요로 채우지 않는다. 누락 목록은 data/processed/section_a/actual_demand_missing_hours.csv에 저장했다.

## 공식 공휴일

- 2023: 18행, received
- 2024: 19행, received
- 2025: 20행, received
- 2026: 22행, received

일요일·토요일은 별도 주말 특성이다. 공휴일 API 행 수가 해당 연도의 전체 휴일 수를 의미하지 않는다. 같은 날의 복수 명칭은 원본에 보존하고 날짜 플래그에서는 중복을 제거한다.

## 수요예측 사용 시각

API date는 목표일이며 당시 공표시각은 아니다. 공식 명세는 일 1회 23시경 갱신을 안내한다. 이번 점검에서 2026-11-19는 HTTP 200, 0건이었다. 미래 날짜 0건을 권한 실패로 분류하지 않는다. hour 01~24는 기간 끝점이므로 00~23시 시작 시각으로 변환했다. D+2·D+3의 아직 공개되지 않은 실제 예측값은 사전에 알았던 것으로 사용하지 않는다.
