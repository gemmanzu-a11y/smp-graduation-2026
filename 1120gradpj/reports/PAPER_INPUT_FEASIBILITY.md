## 원문의 평가 전제

본문 36쪽(PDF 49쪽)은 설명변수 예측오차를 제외하고 SMP 모형을 평가하려고 실적 입력을 사용한 설정을 설명합니다. 본문 38쪽 표 2(PDF 51쪽)에는 입력 정의와 단위, 본문 39쪽(PDF 52쪽)에는 ASOS·EPSIS 출처 및 대상일까지 설명변수 실적을 허용하는 조건이 제시됩니다.

따라서 이 논문의 후향 설명변수 확보 가능성과 우리가 오늘 23시에 미래 D+1~D+3의 입력을 실제 확보할 수 있는지는 분리해야 합니다. 이는 논문이 명시한 실험 전제이며, 원문의 실험을 실시간 서비스 검증으로 바꾸어 해석하지 않습니다.

### 입찰량에서 확인한 제약

[EPSIS 연료원별 입찰량](https://epsis.kpx.or.kr/epsisnew/selectEkmaBddBftChart.do?menuId=040401)의 공개 화면은 연/월만 선택하며 단위는 GWh입니다. 페이지는 다음 달 말 갱신, 최종 정산 자료라는 성격을 설명합니다. 이 자료가 수신되었다고 해서 대상일 시간별 입찰 공급가능용량 MW를 확보했다고 판단하지 않습니다.

논문은 입찰량 출처를 EPSIS라고 명시하지만 정확한 다운로드 경로·원자료 주기·대상일 당시 발표본까지는 확인한 부분에 제시되어 있지 않습니다. 이는 ‘시간별 입찰량이 존재하지 않는다’는 결론이 아니라 현재 공개 경로에서 동일 자료를 확보하지 못했다는 결과입니다. 저자에게 Nuc/Coal 원본 파일명·주기·출처 화면·집계 방식·사용 가능 시각을 확인할 필요가 있습니다.

### 새로운 표본 조회로 보완된 기존 설명

2026년 태양광 실적이 전혀 없는 것은 아닙니다. 새 조회로 1월·7월·9월의 시험 날짜는 반환되는 것을 확인했습니다. 10월·11월 시험 날짜는 정상 HTTP 응답의 0건이므로, 이번 표본만으로 전체 2026 제공 기간이나 최신 경계일을 확정하지 않습니다. 현재 프로젝트의 정규화 학습 자료가 2025년까지만 채워진 사실과 API의 추가 수집 가능성을 구분합니다.

[신재생 발전량 및 설비용량](https://www.data.go.kr/data/15069337/fileData.do)은 시간 열을 가진 과거 파일이지만 연간 배포이고 PPA를 제외합니다. ‘파일에 시간별 값이 있다’와 ‘매시간 최신 용량이 공개된다’는 같은 의미가 아닙니다. 원본에 설비용량 단위가 명시되지 않은 열은 숫자의 크기만 보고 단위를 확정하지 않습니다.

## 계산해서 만들 변수

| 변수 | 생성 방법 | 필요한 주의 |
|---|---|---|
| 보정된 수요 | Demand − Nuc − Coal − Solar | 같은 시간·같은 지역·같은 단위·같은 시장 범위를 맞춰야 함. Nuc/Coal이 없어 현재 완성 불가 |
| Base_bid | Nuc + Coal | 논문의 Coal 포함 범위를 먼저 확인 |
| 일간 대표 기상 | 시간별 기온·일사·일조 자료에서 일별 통계 생성 | 과거는 계산 가능. 미래 일간 최저/최고/합계는 예보가 있어야 함 |
| 월·시간·요일 | 타임스탬프에서 생성 | API 불필요 |
| 시간 코사인 | 논문 convention은 정오 +1/자정 −1, 예: −cos(2πh/24) | 시간의 시작/끝점 정의를 먼저 통일 |
| 전일·익일 휴일 | 확보한 달력에서 날짜를 ±1일 이동해 조회 | 여기서 ‘익일’은 공휴일 일정이며 미래 실측을 의미하지 않음 |
| Ridge 현재 예측치 | origin 시점 가용 입력으로 1단계 모델 계산 | 별도 API 데이터가 아님 |
| 과거 Ridge 잔차 | 이미 관측된 SMP − 당시 Ridge 예측 | 시간 순서 OOF/순차 예측으로 생성. D+2/D+3 대상의 ‘전일 잔차’가 origin 이후이면 사용할 수 없음 |
| 1~6시간 예측 시퀀스·차이 | 1단계가 생성한 예측 배열에서 계산 | 대상 72시간의 1단계 입력이 먼저 확보되어야 함 |

## 추가로 찾은 예보 후보

[한국동서발전 하루 전 전국 태양광 예측](https://www.data.go.kr/data/15144541/openapi.do)의 공식 명세에는 기온, 일사량 예측, 시장/PPA/BTM 용량과 발전 예측을 구분한 필드가 있습니다. 따라서 후보 경로는 존재하지만 이번 키의 실호출은 403이었습니다. 이 서비스가 논문과 같은 범위의 자료인지, 충분한 과거 발표본을 주는지, D+2/D+3까지 제공하는지는 아직 확인하지 못했습니다. 예측 총합과 시장 태양광 `solgenKpx`도 구분해야 합니다.

## 판정

- 확보 또는 직접 생성 가능: SMP, 과거 기상, 시장 태양광 일부 과거분, 시장 신재생 설비용량 과거분, LNG 값, 달력 파생값, 모델 예측치/과거 잔차.
- 현재 권한/범위 조건: 공휴일 인증 API, 기상·태양광 예보 API, PPA 용량, 최신 발전 이력, 모든 미래 horizon의 예측 부하.
- 핵심 미확인: 시간별 원자력·석탄 입찰 원자료와 당시 가용성, LNG 월별 공개일.

모든 논문 변수를 현재 키로 실시간 3일 예측용으로 확보할 수 있다고 결론 내릴 수 없습니다. 원문 전제와 달리 운영 목적에는 미래 실측을 대체할 예측 공변량 설계가 필요합니다.
