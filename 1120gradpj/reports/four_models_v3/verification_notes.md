# 실행·검증 메모

- 실제 XGBoost 및 LightGBM 학습은 각자의 별도 Python 프로세스에서 완료했습니다.
- 두 저장 모델의 Validation 및 Test 예측값이 저장 CSV와 일치했습니다.
- 기존 LSTM·SARIMAX와 25,992개 평가 키·실제 SMP·기준 예측이 일치했습니다.
- 미래 실제 SMP를 변경해도 두 트리 모델의 입력과 예측이 바뀌지 않았습니다.
- 83개 공통 입력 열을 유지했습니다. 값이 상수거나 중요도가 0인 입력도 임의로 삭제하지 않았습니다.

통합 단위검사를 한 프로세스에서 모두 실행했을 때, PyTorch 학습 이후 XGBoost DMatrix 생성에서 macOS native OpenMP의 pthread_mutex_init 오류가 발생했습니다. 트리의 native 학습/저장 통합검사만 실제 학습처럼 별도 Python 프로세스에서 실행하도록 조정했습니다. 자식 프로세스 실패는 부모 테스트 실패로 전파하며 검사를 건너뛰지 않습니다. 모델 설정이나 저장된 성능을 변경한 것은 아닙니다.
