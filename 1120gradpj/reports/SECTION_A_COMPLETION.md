## 수요예측 수집 경로

처음에는 날짜별 API를 수집했으나 HTTP 429가 발생했습니다. 응답 본문 returnReasonCode=22는 일일 서비스 요청제한 횟수 초과입니다. 최종 수집은 공식 KPX 홈페이지의 연간 엑셀 다운로드 기능으로 수행했습니다. 다른 키나 비공개 경로를 사용하지 않았습니다. 향후 API 수집 코드는 429가 발생하면 미수집으로 표시하고 추가 네트워크 요청을 중단합니다.

공식 페이지:
https://new.kpx.or.kr/pssInland.es?mid=a10606090100&device=pc

API 자료와 같은 육지 발전계획용 수요예측인지 제목·단위·지역·시간을 확인하고 실제 2,352시간의 숫자를 대조했습니다. 원본 연간 XLSX는 data/raw/public_forecast_years/에 보존했습니다. 서버 XLSX는 선언된 시트 크기가 A1로 잘못 기록되어 있으므로 read_only 모드의 max_row만 믿지 않고 전체 셀을 읽습니다.

과거 API 일부 결과는 demand_forecast_mainland_api_partial_20261118.csv로 보존했습니다. 최종 demand_forecast_mainland_2023_2025.csv는 공식 연간 파일로 통일했습니다. 예측 대상일과 hour 1~24를 보존하고 시각은 00~23시 시작 슬롯으로 변환했습니다.

원본의 과거 최초 발표시각·수정 전 발표본은 아직 입증하지 않았습니다. target_date는 forecast_origin이 아닙니다. 따라서 파일의 대상일을 그대로 공표일로 간주하지 않습니다.

## 실제 수요의 결측 원인

같은 EPSIS 일별 5분 자료를 다시 받아 기존 원본과 합쳤지만 빠진 관측점이 새로 나오지 않았습니다. 12개의 실제 관측이 모이지 않은 시간은 NaN을 유지했습니다. 미래 보간·0 대체·지난주 값 복사는 하지 않았습니다. 기존에 유효했던 25,209시간 값은 그대로입니다.

- actual_unresolved_hours.csv: 남은 시간·원인·5분 표본 개수
- actual_missing_5min_points.csv: 빠진 관측점 시각
- actual_repair_fetch_status.json: 621일 재조회 결과
- demand_actual_2023_2025_repaired.csv: 기존 정의를 유지한 결과

## 새 공식 실적 자료는 별도 후보

공식 출처:
https://www.data.go.kr/data/15065266/fileData.do

자료 이름은 한국전력거래소_시간별 전국 전력수요량입니다. 육지+제주를 포함하는 발전단 수요예측용 잠정자료이며 원래 단위는 MWh입니다. 2023·2024·2025년 파일을 받아 시간별로 정리했습니다. 2025년 원본 마지막의 비날짜 빈 행 1개는 자료가 아닌 빈 행으로 기록 후 제외했습니다.

이는 EPSIS 5분 현재부하 평균 MW와 동일한 지표라고 확정하지 않았습니다. 한 시간의 MWh를 1시간으로 나누면 평균 MW를 얻을 수 있지만, 집계·수정·범위까지 같아지는 것은 아닙니다. 겹치는 25,209시간의 수치 비교에서 평균 절대 차이는 약 89.20, 최대 절대 차이는 약 4,577.17입니다.

따라서 새 공식 값으로 EPSIS의 비어 있는 시간만 메우지 않았습니다. 기존 지표를 유지할지, 공식 시간별 발전단 수요 시계열을 전체 기간에 채택할지는 팀 공통 입력 정의로 확정해야 합니다. 전국 자료이므로 육지 단독 수요라고 부르지 않습니다.
